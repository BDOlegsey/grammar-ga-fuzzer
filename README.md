
# Адаптивная оптимизация вероятностей правил КС-грамматики

Краткое описание
- Цель: автоматически адаптировать вероятности выбора правил в КС-граmmатике с помощью генетического алгоритма (ГА), чтобы повысить эффективность генерации тестовых входов для SUT (system under test) и улучшить качество фаззинга.
- Подход: представление весов правил как хромосом в популяции ГА; оценка качества по метрикам, получаемым при генерации семплов и запуске SUT; эволюция популяции по поколениям для поиска лучших комбинаций весов.

Структура репозитория
- `include/` — заголовочные файлы проекта.
- `src/` — исходные коды (.cpp).
- `results/` — выходные CSV/текстовые файлы, полученные в экспериментах.

Требования
- Компилятор C++ с поддержкой C++17 (g++, clang, MSVC).
- Платформа: Windows (в репозитории присутствуют примеры запуска для `.exe`).
- Внешних библиотек не требуется (используется стандартная библиотека C++).

Сборка

1) Сборка с помощью MinGW / g++ (рекомендуется для простоты):

```
g++ -O2 -std=c++17 -Iinclude src/*.cpp -o ga_fuzzer.exe
```

2) Сборка в Visual Studio / MSVC (Developer Command Prompt):

```
cl /EHsc /std:c++17 /Iinclude src\*.cpp /Fe:ga_fuzzer.exe
```

Если у вас есть CMake, вы можете быстро создать простой CMakeLists.txt и собрать проект через него.

Запуск

Бинарник запускается как `ga_fuzzer.exe`. Ниже приведены примеры команд, которые использовались в статье и в экспериментах.

Примеры запуска (использованы в статье):

```
.\ga_fuzzer.exe --sut arithmetic --runs 20 --pop 40 --gen 60 --samples 150 --seed 42
.\ga_fuzzer.exe --sut csv        --runs 20 --pop 40 --gen 60 --samples 150 --seed 42
.\ga_fuzzer.exe --sut url        --runs 20 --pop 40 --gen 60 --samples 150 --seed 42
.\ga_fuzzer.exe --mode sweep     --sut arithmetic --sweep-pop "20,40,80" --sweep-mut "0.05,0.12,0.25" --runs 10 --seed 42
.\ga_fuzzer.exe --mode ablation  --sut arithmetic --runs 15 --seed 42
```

Описание ключевых параметров командной строки
- `--sut <name>` — выбор SUT (например, `arithmetic`, `csv`, `url`).
- `--runs <n>` — количество независимых запусков (репликаций) эксперимента.
- `--pop <n>` — размер популяции ГА.
- `--gen <n>` — число поколений в ГА.
- `--samples <n>` — количество семплов, генерируемых для оценки каждой особи.
- `--seed <n>` — зерно генератора случайных чисел для воспроизводимости.
- `--mode <mode>` — режим работы (например, стандартный режим оптимизации или специальные режимы `sweep`/`ablation`).
- `--sweep-pop` — список значений для параметра популяции при режиме `sweep`.
- `--sweep-mut` — список значений для вероятности мутации при режиме `sweep`.

Файлы результатов
- После запуска экспериментов результаты сохраняются в папке `results/` в виде CSV и текстовых файлов (логи, метрики, веса правил и т.д.). Примеры: `generations.csv`, `runs.csv`, `rule_weights_*.csv`.

Рекомендации по воспроизведению экспериментов
- Используйте указанные параметры `--seed` для воспроизводимости.
- Для sweep-экспериментов заранее подготовьте список значений через запятую в кавычках, как показано в примерах.
- Для анализа результатов используйте скрипты обработки CSV (например, pandas в Python) или импортируйте их в статистические инструменты.

Контекст научной работы
- Этот код использовался для исследования влияния адаптивного изменения вероятностей правил грамматики на эффективность фаззинга. Эксперименты включали сравнительные прогоны для нескольких типов SUT, исследование сеттингов ГА (sweep) и абляционные исследования для оценки вклада компонентов метода.
