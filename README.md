# Grammar GA Fuzzer

Инструмент для генерации тестовых входных данных на основе контекстно-свободных грамматик с использованием генетических алгоритмов. Реализует адаптивную стратегию поиска, направленную на увеличение покрытия и выявление ошибок.

## Назначение

Проект предназначен для автоматизированного тестирования парсеров и программ, принимающих структурированный ввод. Генерация входных данных осуществляется с учётом заданной грамматики, а эволюционная оптимизация позволяет находить более «эффективные» тесты по заданным метрикам.

## Основные возможности
генерация строк по грамматике с ограничением глубины и длины;
применение генетического алгоритма (селекция, кроссовер, мутация);
адаптивная функция приспособленности;
поддержка нескольких метрик (покрытие, ошибки, разнообразие и др.);
проведение серии независимых запусков с агрегированием статистики;
сравнение базового и адаптивного подходов.
Сборка

## Компиляция выполняется с использованием g++:
```bash
g++ -std=c++17 -O2 -Iinclude src/*.cpp -o adaptive_fuzzer
```
## Запуск

Пример запуска:
```bash
./adaptive_fuzzer \
  --runs 30 \
  --pop 30 \
  --gen 30 \
  --samples 60 \
  --mut 0.12 \
  --cross 0.85 \
  --alpha 0.5 \
  --beta 0.25 \
  --gamma 0.15 \
  --delta 0.10 \
  --seed 42 \
  --depth 15 \
  --maxlen 128
```

## Параметры
`--runs` — количество независимых запусков;

`--pop` — размер популяции;

`--gen` — число поколений;

`--samples` — число тестов, оцениваемых за итерацию;

`--mut` — вероятность мутации;

`--cross` — вероятность кроссовера;

`--alpha`, `--beta`, `--gamma`, `--delta` — веса компонентов функции приспособленности;

`--seed` — начальное значение генератора случайных чисел;

`--depth` — максимальная глубина вывода грамматики;

`--maxlen` — максимальная длина генерируемой строки.

## Выходные данные

Программа выводит агрегированные результаты по сериям запусков:

coverage — доля достигнутого покрытия;
bugs — количество выявленных ошибок;
runtime — время выполнения;
fitness — значение функции приспособленности;
novelty — новизна решений;
diversity — разнообразие популяции;
avg_input_len — средняя длина входных данных.

Также приводится статистическое сравнение базового и адаптивного режимов.

## Примечания
Проект ориентирован на воспроизводимость: использование `--seed` фиксирует последовательность случайных чисел.
Параметры функции приспособленности напрямую влияют на баланс между исследованием и эксплуатацией.
Ограничения `--depth` и `--maxlen` предотвращают экспоненциальный рост структуры входных данных.
